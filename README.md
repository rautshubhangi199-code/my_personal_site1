## 🚀 Free Hosting & 1-Click Deployment Guide

Follow these simple steps to get your portfolio hosted **100% free forever** on **Vercel** (just like `portfolio-aditya-khule.vercel.app`):

### Option 1: Deploy with Vercel (Recommended - 2 Minutes)
1. **Create a Free Vercel Account**:
   - Go to [vercel.com/signup](https://vercel.com/signup).
   - Choose **"Continue with GitHub"** (log in with your GitHub account: `https://github.com/rautshubhangi199-code`).
2. **Deploy directly via GitHub**:
   - Create a new repository on your GitHub (e.g., `portfolio`).
   - Push this folder to that repository:
     ```bash
     cd /Users/vedantraut/.gemini/antigravity/scratch/portfolio
     git remote add origin https://github.com/rautshubhangi199-code/portfolio.git
     git push -u origin main
     ```
   - On the Vercel dashboard, click **"Add New..."** → **"Project"**.
   - Select your `portfolio` repository and click **Deploy**.
   - Your site will instantly go live with a free URL like: `https://shubhangi-raut.vercel.app`!
3. **Or Deploy via Vercel CLI**:
   ```bash
   npx vercel /Users/vedantraut/.gemini/antigravity/scratch/portfolio
   ```

### Option 2: Deploy with GitHub Pages (100% Free)
1. In your GitHub account (`rautshubhangi199-code`), create a repository named `rautshubhangi199-code.github.io`.
2. Push these files to GitHub.
3. Go to **Settings** → **Pages** → Source: select `main` branch → Click **Save**.
4. Your portfolio is live at `https://rautshubhangi199-code.github.io`!
